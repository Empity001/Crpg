# Ajustes visuales: Acerca del servidor, Guías e identidad

## Acerca del servidor
- Las imágenes conservan su relación de aspecto original.
- Se muestran completas con `object-fit: contain` y nunca se recortan para llenar una caja.
- Se limitan al ancho disponible y a una altura cómoda de pantalla.

## Recursos visuales de Guías
- La miniatura se puede pulsar para abrir el visor de pantalla completa.
- Si el recurso también enlaza con otra Guía, el nombre mantiene ese enlace por separado.
- Se añadió indicador de ampliación y soporte de teclado/foco.

## Colores del nombre del servidor
El editor de colores ahora incluye un grupo `Identidad del servidor` con:
- Nombre del servidor: color de `CULONES`.
- Acento del nombre: color de `-RPG`.
- Subtítulo del servidor: color de `Página oficial` o `Panel de Administración`.

Las opciones funcionan tanto para la paleta local del navegador como para la paleta global del servidor. No requieren SQL.
