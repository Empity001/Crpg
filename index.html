Acerca de culones-rpg

Servidor de Minecraft con sistema RPG y gacha. Esta web sincroniza en tiempo real con nuestro Discord — cada evento importante del servidor queda registrado aquí como un log público.

Solo visible para administradores

📝 Borradores

Borradores guardados localmente en este dispositivo. Los marcados con [local] nunca fueron publicados.

No hay borradores guardados.

📤 Exportar

Exporta el contenido de la web a un archivo Excel (.xlsx) o JSON. Los archivos Excel incluyen encabezados con estilo, filtros automáticos y organización profesional para abrir directo en Excel o Google Sheets.

📜 Logs

El Excel incluye 4 hojas relacionadas — Logs, Mobs, Items y Bloques Libres — con encabezados estilizados, colores, filtros y anchos ajustados.

🏆 Tierlist

📦 Todo

El Excel completo incluye todas las hojas: Resumen, Logs, Mobs, Items, Bloques Libres, Tierlist, Armas, Categorías y Configuración.

📥 Importar

Importa un archivo JSON generado por esta misma herramienta. Si hay conflictos de IDs, podrás elegir qué hacer con cada uno.
